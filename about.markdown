# About This Portfolio

This site is my Network Technology Portfolio for documenting hands-on labs completed during my Network+ coursework.

The purpose of this portfolio is to show my progress with networking concepts, troubleshooting, configuration, security, and technical documentation. Each lab post will include the lab objective, tools used, steps completed, issues encountered, and lessons learned.

## Skills Documented

This portfolio will include work related to:

- Network design and configuration
- IP addressing and subnetting
- Switching and routing concepts
- Network troubleshooting
- Wireless and wired networking
- Network security fundamentals
- System and command-line tools
- Technical documentation

## Portfolio Goal

My goal is to build a clear record of practical networking experience that I can use for class submissions, future job applications, internships, and continued professional growth.
